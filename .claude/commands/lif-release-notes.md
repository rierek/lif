# Prepare LIF Release Notes

Read `.claude/skills/lif-release/SKILL.md` and follow it.

Use `wiki/releases/vX-Y-Z.md` as canonical release prose. Do not create `.docs.local/RELEASE.md`.

Drafting and `just release-notes-check vX.Y.Z` are local-only. Do not tag, push, run GoReleaser, or edit a GitHub release without explicit PO authorization.
