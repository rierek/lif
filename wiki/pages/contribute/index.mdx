Raw draft. Repository layout:

<FileTree>

- cmd/
  - lif/ CLI entry point
  - lif-docgen/ generates command reference pages
- internal/commands/ command definitions (source of truth for help, completion, reference)
- pkg/item/ item file format (`Parse`, `Render`)
- wiki/
  - pages/ public site content (Markdown)
  - assets/ screenshots, GIFs, figures
- site/ Astro + Starlight config only
- **.lif/** item store

</FileTree>

- Change a command: edit its definition. Help, completion and reference follow at build.
- Change docs: edit `wiki/pages`, run `just docs-dev`.
