**Install Lif and run it in one minute.** Copy one command, then check the result with `lif version`.

## Install

macOS, with Homebrew:

```sh
brew install xRiErOS/lif/lif
```

Linux or macOS, with the install script:

```sh
curl -fsSL https://raw.githubusercontent.com/xRiErOS/lif/main/install.sh | sh
```

Linux or macOS, with Nix:

```sh
nix profile install github:xRiErOS/lif
```

Check that it works:

```sh
lif version
```

Output of a development build. A release build shows its release version instead of `dev`:

```text
lif dev (135e76e-dirty) built 2026-10-14T18:41:07Z
custom front matter: preserved
```

There is no `lif --version` flag ([3slb]). The command is `lif version`, and `lif version --json` prints the same data as JSON.

Next, run `lif init` in your project folder. [First steps](../first-steps/) takes you through it.

## Requirements

- Release archives exist for Linux (`x86_64`, `arm64`, `i386`), macOS (`x86_64`, `arm64`) and Windows (`x86_64`, `arm64`, `i386`).
- The install script supports Linux and macOS. Windows users download the `.zip` archive.
- Building from source needs Go (the module requires Go 1.26) and `mise`, which installs Go, Node.js and pnpm.
- Each binary stands alone. `lif-serve` is only needed for the web UI.

## All install methods

| Method | Command | Use it when |
|---|---|---|
| Homebrew | `brew install xRiErOS/lif/lif` | You are on macOS. Installs `lif` and `lif-serve`. |
| Install script | `curl -fsSL https://raw.githubusercontent.com/xRiErOS/lif/main/install.sh \| sh` | You are on Linux or macOS and want no package manager. Installs both binaries. |
| Nix | `nix profile install github:xRiErOS/lif` | You use Nix. `nix run github:xRiErOS/lif -- version` tries it without installing. Installs both binaries, and `lif-serve` serves the web UI. |
| Release archive | Download `lif_<Os>_<arch>.tar.gz` (`.zip` on Windows) from the Releases page | You are on Windows or want to pin a file. Installs both binaries. |
| `go install` | `go install github.com/xRiErOS/lif/cmd/lif@latest` | You only need the CLI. Installs `lif` only. |
| Build from source | `git clone https://github.com/xRiErOS/lif.git`, then `mise install`, `mise run setup`, `mise run build` | You want an unreleased build. |

- Homebrew installs a cask from the tap `xRiErOS/homebrew-lif`. On macOS it removes the quarantine attribute from both binaries.
- The install script downloads the release archive and verifies it against `checksums.txt` when `sha256sum` or `shasum` exists. It only warns, and still installs, if `checksums.txt` cannot be downloaded or neither tool exists. It runs `lif version` at the end.
- Script variables: `LIF_VERSION` (default: latest release), `LIF_BIN_DIR` (default: `$HOME/.local/bin`), `LIF_REPO` (default: `xRiErOS/lif`). The script prints a note when `LIF_BIN_DIR` is not on `PATH`.
- Archive names use title-cased OS and the arch names `x86_64`, `arm64`, `i386`, for example `lif_Linux_x86_64.tar.gz`. Verify the archive against `checksums.txt`, then put `lif` and `lif-serve` on your `PATH`.
- After a source build, install the binaries from the repository root, for example `install -m 755 lif lif-serve "$HOME/.local/bin/"`.
- A `lif-serve` built by `go install` of the module source embeds no web assets and returns 404 for the browser UI. Use Homebrew, the script or an archive for a working `lif-serve`.

## The binaries

| Binary | Purpose | Default port |
|---|---|---|
| `lif` | CLI and TUI (`lif tui`) | none |
| `lif-serve` | Web UI and GraphQL API | 8080 |

`lif-serve` has no version command. Check the version with `lif version`.

## Shell completion

`lif completion bash|zsh|fish|powershell` prints a completion script for your shell. It completes commands, flags and item IDs. Run `lif completion zsh --help` for how to load it.

## Update and uninstall

- Homebrew: `brew upgrade --cask lif`.
- Install script: run it again. `LIF_VERSION` pins a release tag.
- `go install`: run the command again. Release archive: download and extract the new archive. Source build: pull and run `mise run build` again.
- Before an upgrade, commit pending item changes and read the [release notes](../../releases/) for breaking changes.
- Uninstall: delete `lif` and `lif-serve` from the install directory (script default: `$HOME/.local/bin`). Lif has no uninstall command. Your stores (`.lif/`, `.lif.yml`) stay as normal files in your projects.
- Old `.beans` stores are still read in place after you install Lif.

## Limits

- Run `lif completion` and `lif help <cmd>` inside a project folder: outside one they can fail. Known as [mgx8].
