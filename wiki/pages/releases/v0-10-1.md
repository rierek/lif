## Headline

Patch release. It fixes dead GraphQL subscriptions and makes the build and release tooling reliable.

## New commands and flags

None.

## Fixes

- Gin is updated to v1.12.0. This fixes GraphQL subscriptions that did not deliver events.
- gqlgen is updated so code generation works under Go 1.27. Code generation now runs before the frontend build.
- The `release:patch`, `release:minor` and `release:major` recipes create annotated tags and print usable hints.
- CI installs the browser and shell it needs for end-to-end tests. Unreliable dependency caches are removed.

## Upgrade notes

No action needed.
