## Headline

Batch work gets shorter. Filter flags take comma-separated values, and `lif update` accepts several IDs in one call.

## New commands and flags

- Filter flags of `list`, `roadmap` and `next` accept comma-separated values, for example several statuses in one flag.
- `lif show` filters by status, type, priority and tag.
- `lif update` takes multiple item IDs.

## Fixes

None in this release.

## Upgrade notes

No action needed. Calls with one value work as before.
