## Headline

Patch release with two fixes.

## New commands and flags

None.

## Fixes

- `lif order <id> --last` is rejected when no sibling has a manual order. Before, it placed the item first, the same result as `--first`. Give the siblings an order first, then use `--last`.
- The release recipe watches only the workflow run that its own tag push created.
