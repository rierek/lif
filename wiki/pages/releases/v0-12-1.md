Patch release with two user-visible fixes.

## Fixes

- `lif rename --no-slug` keeps the prefixed ID of the item.
- `NO_LIF_DIR` is now emitted when no store is found. The order hint is corrected.
- Test helpers no longer build the binary, and e2e fixtures disable git hooks. These change tests only.
