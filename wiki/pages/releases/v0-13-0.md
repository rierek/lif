## Headline

Lif absorbs the separate `bt` terminal UI. It runs as `lif tui` inside the main binary. The separate `lif-tui` binary and the old bundled TUI are removed.

## New commands and flags

- `lif tui` starts the terminal UI. It drives the `lif` binary.
- The blocking and parent pickers default to open items.
- The detail view uses the box form by default.
- The user config moves to `~/.config/lif/tui`. The legacy location is still read.

## Fixes

- The banner and the TUI texts name lif and items.
- The agent prompt cites a real worktree mutation.

## Upgrade notes

Replace calls to `lif-tui` and `bt` with `lif tui`.

## Limits

[179g] The TUI ignores `display.theme`, offers only built-in value lists, and its quit dialog says `bt`. See [Known limitations](../../known-limitations/).
