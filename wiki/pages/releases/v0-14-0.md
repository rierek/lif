## Headline

Lif has a public documentation site on GitHub Pages. This release also ships the 0.13.1 bugfix line and a Nix flake. There is no separate v0.13.1 tag.

## New commands and flags

- `lif check` validates status, priority, tags and rank.
- A Nix flake (`flake.nix`) installs and runs Lif declaratively. It comes from the contributor mipmip in pull request 1.
- The documentation site has a generated command reference, a release timeline, a Known limitations page and a Mermaid diagram.

## Fixes

- `lif update --title` renames the file when the slug is derived from the title.
- A type change validates the hierarchy.
- GraphQL `createItem` sets the default status.
- Worktree names and paths are validated.
- The default sort help and the wiki list the manual order.
- CI pins Go 1.26, because Go 1.27 breaks gqlgen codegen.

## Upgrade notes

No migration is needed. `lif check` can report problems in existing stores that earlier versions accepted.

## Limits

See [Known limitations](../../known-limitations/). The command-page supplements (docgen) move to 0.15.
