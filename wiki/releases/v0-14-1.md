## Headline

The GitHub owner changed from `xRiErOS` to `rierek`. This patch aligns the install channels and the documentation with the new owner. The documentation lives on one site now.

## Breaking changes

- The Go module path is `github.com/rierek/lif`. `go install github.com/xRiErOS/lif/cmd/lif@latest` no longer works. Use `go install github.com/rierek/lif/cmd/lif@latest`.

## Install channels

- Homebrew: `brew install rierek/lif/lif`. The tap is `rierek/homebrew-lif`.
- Install script: `curl -fsSL https://raw.githubusercontent.com/rierek/lif/main/install.sh | sh`. `LIF_REPO` defaults to `rierek/lif`.
- Nix: `nix profile install github:rierek/lif`.

## Documentation

- The site has two new pages: [Troubleshooting](../../overview/troubleshooting/) and [Upgrading](../../overview/upgrading/).
- The flat `wiki/*.md` and `wiki/commands/*.md` pages are removed. The documentation site is the single source.
- The README is rewritten as an entry point into the documentation.
- Links and install commands on the site use `rierek`.

## Upgrade notes

If you installed through Homebrew, replace the tap. Run `brew uninstall --cask lif`, then `brew untap xRiErOS/lif`, then `brew install rierek/lif/lif`. Update the module path in scripts that call `go install`. [Upgrading](../../overview/upgrading/) lists every old form, new form and migration step.
