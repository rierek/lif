## Headline

This patch fixes two interaction bugs and reworks the documentation. No configuration or file format changes.

## Fixes

- `lif tui`: after an edit, the cursor stays on the edited row. Before, rows hidden by the archive default, a search or a facet filter shifted the cursor to another item.
- `lif create -i`: a round after `create next` asks only for what you did not carry. The title is always asked. Type and priority are asked when unticked, the parent when parent or type is unticked. The body field opens right after the form, then the action menu follows. See [`lif create`](../../reference/commands/lif-create/).

## Documentation

- New feature pages: [Interactive shell](../../features/interactive-shell/) (`lif create -i`, `lif pick`) and [Tasks and hooks](../../features/tasks-and-hooks/). [Automation](../../features/automation/) links to the moved Tasks and Hooks sections.
- The [configuration reference](../../reference/configuration/) is split into [tasks](../../reference/configuration/tasks/), [hooks](../../reference/configuration/hooks/) and [types and statuses](../../reference/configuration/types-and-statuses/). The URL of the main page is unchanged.
- The TUI reference shows screenshots of the create form, the status menu, the parent picker, the delete confirmation, tag management, the settings form and the filter menu.
- Reference pages no longer carry "measured on Lif 0.x" stamps.
- TUI screenshots and GIFs are generated during the docs deploy and are no longer stored in the repository. The README image loads from the docs site.
