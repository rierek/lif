## Headline

This release adds two compact yank sequences to the TUI, a `--item` flag for `lif tui`, and shows open milestones and epics without leaves on the roadmap. Dependencies are patched for known advisories. No file format changes.

## New

- TUI: `yi` copies the focused item as `ID - Title`. `yl` copies that line plus its direct children as `  +-- ID - Title`. `yl` lists only children that pass the active search, facets and archive visibility; folds, scrolling and the Ready list do not matter. `yy`, `ym` and `yt` still copy all children. See [Key bindings](../../reference/tui/key-bindings/).
- `lif tui [repo-path] --item <id>` opens the item's detail view once after loading. It takes a full ID or the short ID without the configured prefix. An unknown ID fails before the terminal starts; later navigation and reloads stay where you are. See [Start and repositories](../../reference/tui/start-and-repositories/). This is the command-line contract only; a caller such as an editor or terminal multiplexer must be wired separately.

## Fixes

- `lif roadmap` and the TUI show open milestones and epics that have no leaves. Before, they appeared under `Not on roadmap`.
- Security updates: quic-go 0.59.1, SvelteKit 3.1.1 with the static adapter 4.0.1, Vitest 5.0.5, minimatch 11.0.1 (override), Astro 7.4.7 for the documentation site, and Node 24.22.3 for development. The access defaults of `lif serve` are unchanged.
